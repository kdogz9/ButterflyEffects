The Idea

Butterfly Effects was created as a central portfolio for my social media, video, design and digital work.

The Structure

Rather than displaying every project on one large page, the portfolio is separated into categories.

Visitors can select an area of work, explore the projects within that category and then open an individual case study.

Development

The website was built using HTML, CSS and lightweight JavaScript and designed to run through GitHub Pages.
